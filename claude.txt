One note: the Guitar Link’s model number is most likely UCG102, not UC6102. It’s a mono, one-channel USB input and usually shows up in Windows as a generic USB audio device. That means you’ll probably want ASIO4ALL or FlexASIO for low latency, which I’d verify when you test it.

Best approach

I’d build it as a real-time audio engine with a separate UI.

Audio thread: takes the guitar input, runs it through an ordered chain of effects, and sends it to the output. Nothing in that thread can allocate memory, take locks, or touch the UI.
Effect interface: every pedal implements the same small interface (prepare, process, parameters, bypass). The compressor is just the first one, and new pedals plug in without changing the engine.
Pedalboard model: the board is an ordered list of pedal instances. Dragging and dropping in the UI edits that list, and the audio thread picks up the change safely.
Knobs: parameter changes go to the audio thread through atomic values and get smoothed to avoid crackle.
Latency: aim for 64 to 128 sample buffers, which should land you around 10 to 15 ms round trip.
Language options

Option	Pros	Cons
C++ with JUCE (my pick)	Industry standard for audio. Handles ASIO and WASAPI device selection, has drag-and-drop UI built in, and can later export as a VST3 plugin	Steeper learning curve
C# with NAudio and WPF/WinUI	Fastest way to a polished drag-and-drop UI	Garbage collection can cause glitches unless you’re careful in the audio code
Rust with cpal and egui	Very safe for real-time audio	More work to build a nice pedalboard UI
Python with sounddevice and PySide	Great for prototyping the DSP	Latency is too high for comfortable live playing
Electron / Web Audio	Easy UI	Poor audio latency on Windows, so I’d avoid it
Compressor design

The compressor needs threshold, ratio, attack, release, knee, makeup gain, and a dry/wet mix. The signal path is a level detector feeding an envelope follower, then a gain computer with a soft knee, then the gain applied plus makeup.

The main decision is JUCE versus C#. If you already know C#, that gets you a working pedalboard fastest. If you want the best audio performance and the option of a VST later, go with JUCE.
